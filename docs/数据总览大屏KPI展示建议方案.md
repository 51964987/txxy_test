# 数据总览大屏 — KPI/卡片/图表展示建议方案

> 文档定位：参考互联网主流数据大屏（社区/内容平台驾驶舱）的最佳实践，结合本项目**已有后端数据字段**，给出「建议新增/调整」的展示方案。
> 现状基础（历史，2026-08-25 前）：累计帖子、今日新增、昨日新增、近7日新增、累计用户、活跃用户 6 张 KPI 卡；每日新增趋势（总版块+各版块双折线）；版块分布环形图；版块分布排行榜；点赞/回复最高帖热门榜。2026-08-26 已合并为 4 张 KPI 卡（见第一节）。
> 颜色体系沿用现有科技蓝 `#2f6fed` + 确定性版块色板 `FID_PALETTE`，不引入新 UI 依赖。
> 状态：✅ 已实施（2026-08-25）。P0/P1/P2 全部落地，详见末尾「实施记录」。
> 2026-08-26 更新：KPI 区已按《[KPI指标合并方案](./KPI指标合并方案.md)》由 7 张合并为 4 张（信息无损），本文档 KPI 章节相应收敛为合并后状态。

## 一、KPI 指标卡（顶部，合并为 4 张，主指标 + 副指标双层）

> 实施结果（2026-08-26）：按《KPI指标合并方案》将 6 张 + 版块总数卡合并为 **4 张**，原 7 个字段全部保留（信息无损）。

| 卡片 | 主指标 | 副指标（合并内容） | 数据来源 |
|---|---|---|---|
| 累计帖子 | `total` | 今日 +`today` · 覆盖版块数 `fidDist.length` | `/stats/overview` + 前端 `fid_dist` |
| 今日新增 | `today` | 较昨日环比 ↑/↓（`kpiSub.todayDiff`）· 昨日 `yesterday` | 计算 |
| 近7日新增 | `week_new` | 日均 `weekAvg` 条 · 昨日占 `yesterdayShare`% | 计算 |
| 累计用户 | `total_users` | 活跃 `active_users` · 活跃率 `activeShare`%（活跃/累计） | 已有 |

**说明（2026-08-26）**：数据更新时间已常驻 Header（见第七节），不单开卡；版块总数不再单开卡，已并入「累计帖子」副指标。

## 二、核心趋势图表（建议增强，不替换）

1. **每日新增趋势（总版块）** — 保留折线 + 每日描线动画 + 7日均线标注（已有）。
   - 建议：天数切换默认 7 天，增加 `14 / 30` 天选项（后端 `trend` 接口已支持 `days` 参数）。
2. **各版块每日趋势（多系列折线）** — 保留，保留总↔各版块联动高亮。
   - 建议：版块过多时默认只显示 Top 6，其余收进图例折叠（避免 13 条线糊成一团）。

## 三、版块分布（建议保留双可视化）

1. **环形图** — 保留，中心动态显示悬停版块占比，自动轮播高亮（已有）。
2. **版块分布排行榜** — 保留 DataV 无缝轮播 + 总量/今日/昨日排序切换（已有）。
   - 建议：排行榜与环形图保持同色板联动（已做），无需改。

## 四、热门内容榜（建议保留并扩展维度）

现有：点赞最高帖、回复最高帖（各版块）无缝滚动榜。
建议新增（需后端 `boards` 接口扩展，标注「待定」）：
- 今日新增帖最多的版块 Top（与现有排行榜互补，一个看"存量"一个看"增量"）。
- 24h 内升温最快帖（按 `today-yesterday` 增量排序）—— 复用现有 `barDeltaOf` 逻辑即可。

> **实施调整说明**：原"升温最快帖（按 today-yesterday 增量）"需对同一帖子做跨日快照 join，实现复杂度高且数据可靠性弱。按项目「消除复杂场景而非加兜底」「不过度优化」原则，调整为**「今日热议帖」**：取今日(date=today)新增帖中互动量(likes+replies)最高的帖 Top，语义清晰、零复杂查询。

## 五、建议新增「地域/设备」类看板（互联网大屏常见，但本项目无对应数据）

## 六、布局与视觉建议（大屏化）

参考互联网大屏惯用布局，建议（可结合已实施的全屏B沉浸模式）：

```
┌──────────────────────────────────────────────────────────┐
│  Header: 标题 + 更新时间 + 自动刷新开关 + [全屏]            │
├──────────────────────────────────────────────────────────┤
│  KPI 卡区 (4 张，一行等分)                                  │
├──────────────────────────────────────────────────────────┤
│  每日新增趋势(总)       │  各版块每日趋势(多系列)            │
│  (折线, 7/14/30天)     │  (联动高亮)                       │
├───────────────┬───────┴───────────┬──────────────────────┤
│ 版块分布环形图  │  版块分布排行榜    │  热门榜(点赞/回复)      │
│ (轮播高亮)     │  (无缝滚动)        │  (无缝滚动)            │
└───────────────┴────────────────────┴──────────────────────┘
```

- 暗色科技风背景（大屏标配），卡片半透明玻璃拟态；现有为白底卡片，若做沉浸全屏建议加一套 `immersive` 暗色主题（复用 `immersive-on` class 钩子）。
- 数字滚动 `RollingNumber` 已用，保留。
