# 数据总览大屏信息总结

> 本文档总结数据总览页面（DashboardView）涉及的全部信息模块、API接口、交互行为及技术实现。

---

## 一、页面概览

数据总览大屏是系统首页（路由 `/`），用于展示整体数据统计与概览信息。页面采用**分区加载**策略，将内容分为 P0（首屏立即加载）和 P1（视口懒加载）两级优先级。

### 页面布局结构（从上到下）

```
┌─────────────────────────────────────────────────────────────────┐
│  Header（顶部栏：Logo + 导航 + 更新时间 + 自动刷新开关）         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ① 6 张 KPI 指标卡（横排）                                      │
│     ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐                │
│     │累计│ │今日│ │昨日│ │近7 │ │累计│ │活跃│                │
```

## 二、信息模块详解

### 2.1 KPI 指标卡（6 张）

| # | 指标名称 | 主数值 | 副指标 | 图标 | 渐变色系 |
|---|----------|--------|--------|------|----------|
| 1 | **累计帖子** | 总帖子数（千分位） | 今日新增 +N | `Collection` | 蓝 `#4f83f1 → #2f6fed` |
| 2 | **今日新增** | 当日帖子数（滚动数字） | 较昨日 ↑/↓ N% | `TrendCharts` | 绿 `#34d399 → #10b981` |
| 3 | **昨日新增** | 昨日帖子数（滚动数字） | 占近7日 N% | `Calendar` | 黄 `#fbbf24 → #f59e0b` |
| 4 | **近 7 日新增** | 近 7 日帖子数（滚动数字） | 日均 N 条 | `DataLine` | 紫 `#a78bfa → #8b5cf6` |
| 5 | **累计用户** | 去重作者总数（滚动数字） | 今日活跃 N | `User` | 红 `#f87171 → #ef4444` |
| 6 | **活跃用户** | 今日活跃作者数（滚动数字） | 占累计 N% | `UserFilled` | 青 `#22d3ee → #06b6d4` |

#### 副指标逻辑说明
- **今日新增 vs 昨日新增对比**：计算 `(today - yesterday) / yesterday × 100%`，上升显示绿色 `↑`，下降显示红色 `↓`
- **昨日占近7日比例**：`yesterday / week_new × 100%`
- **近7日日均**：`week_new / 7`，向下取整
- **活跃用户占比**：`active_users / total_users × 100%`

#### 动画效果
- 使用 `RollingNumber` 组件实现数字滚动过渡动画（非首次加载时显示实时数值）

#### 数据来源
- API: `GET /api/stats/overview`
- 返回类型: `Overview { total, today, yesterday, week_new, total_users, active_users, latest_created_at, ... }`

### 2.2 每日新增趋势图

#### 展示内容
- **类型**: ECharts 平滑折线图（带面积渐变填充）
- **时间维度**: 支持 `7天` / `30天` / `90天` 切换
- **X 轴**: 日期（MM-DD 格式，自动根据天数调整）
- **Y 轴**: 新增帖子数（整数，最小值 1）

#### 图表特性
| 特性 | 说明 |
|------|------|
| **markPoint** | 自动标注最高点（`max`）和最低点（`min`），符号大小 46px |
| **面积渐变** | 从 `rgba(47,111,237,0.22)` 到 `rgba(47,111,237,0.02)` 的线性渐变 |
| **动画入场** | 逐点描线生长效果，每点延迟 24ms，总时长 900ms |
| **数据更新动画** | 600ms 平滑过渡 |
| **DataZoom** | 数据点 > 31 时自动启用缩放组件（含滑动条） |

#### Tooltip 内容
```
日期
新增帖子：N 条（较上日 +N/-N）
```

#### 动态效果（数据大屏风格）
- **Tooltip 自动轮播**：沿时间轴从右往左（最新 → 最早）依次展示每个数据点的 tooltip
  - 单点停留：900ms
  - 维度阶段间隔：1500ms
  - 维度切换序列：`7天 → 30天 → 90天 → 7天` 循环
  - 维度切换动画：淡出旧图表（300ms）→ 加载新数据 → 淡入新图表（300ms）
  - 鼠标悬停暂停轮播，移出恢复
  - 维度衔接：切换到 30/90 天时，轮播起点与上一阶段终点在时间轴上连续

#### 数据来源
- API: `GET /api/stats/trend?days=N`
- 返回类型: `TrendPoint[] { date, count }`

### 2.3 版块分布 · 排行榜

#### 展示内容
- **类型**: 排名列表（类 DataV 风格）
- **固定可视区**: 8 行 × 40px 高度
- **滚动轮播**: 每 2000ms 平滑向上滚动一行，末尾补位实现无缝循环

#### 每行信息
```
[排名徽章] [版块名称(fid)] [今日新增 N 条 / 最新日期] [N 条 (M%)]
```

#### 排名徽章样式
| 排名 | 样式 |
|------|------|
| 第 1 名 | 金色渐变 `#fbbf24 → #f59e0b` |
| 第 2 名 | 银色渐变 `#cbd5e1 → #94a3b8` |
| 第 3 名 | 铜色渐变 `#e8a17c → #cd7f5a` |
| 4+ | 灰色 `#e4e7f0` |

#### 交互行为
- 悬停：高亮行背景色为浅蓝色 `#f0f4ff`
- 点击：跳转至帖子浏览页，并预选该版块（`/posts?fid=xx`）
- Tooltip：显示「最近抓取日期」「今日新增」「昨日新增」详细信息
- 鼠标悬停暂停滚动，移出恢复

#### 数据来源
- API: `GET /api/stats/fid_dist`
- 返回类型: `FidDistItem[] { fid, name, count, latest_date, today_count, yesterday_count }`

### 2.4 版块分布 · 环形图

#### 展示内容
- **类型**: ECharts 环形饼图（Donut Chart）
- **内外半径**: `42%` ~ `68%`
- **中心信息**: 动态显示当前高亮版块的名称、帖子数和占比

#### 图表特性
| 特性 | 说明 |
|------|------|
| **色板** | 确定性 13 色色板，同一版块在环形图和排行榜中使用一致颜色 |
| **标签** | 仅占比 ≥ 4% 的版块显示外部标签 + 引导线，避免重叠 |
| **圆角扇区** | 6px 圆角，白色描边 2px |
| **图例方向** | 大屏（≥1440px）右侧纵向，中/小屏底部横向 |
| **中心位置** | 大屏 `left:38%, top:50%`，中/小屏 `left:50%, top:42%` |

#### 中心动态信息
- 轮播模式下：显示当前轮播项的 **名称 · 数量 · 占比%**
- 默认状态：显示 **累计帖子** 总数
- 颜色与对应版块一致

#### 动态效果
- **自动轮播高亮**: 每 2200ms 自动高亮下一个版块，中心信息同步更新
- **鼠标悬停**: 暂停自动轮播，中心显示悬停项信息
- **鼠标移出**: 恢复自动轮播
- **点击扇区**: 跳转至帖子浏览页（`/posts?fid=xx`）
- **点击图例**: 同点击扇区行为，跳转至对应版块

#### 数据来源
- 同排行榜：`GET /api/stats/fid_dist`

---

### 2.5 热门榜（P1 懒加载）

#### 展示内容
- **点赞最高帖（各版块）**: 每个版块点赞数最高的 1 条帖子
- **回复最高帖（各版块）**: 每个版块回复数最高的 1 条帖子

#### 每条信息
```
[排名徽章] [版块标签] [帖子标题] [★ 点赞数 / 💬 回复数]
```

#### 交互行为
- 点击卡片：在新标签页打开帖子原始链接（`window.open(url, '_blank')`）
- 鼠标悬停：卡片背景变为浅蓝 `#f0f4ff`，添加轻微阴影
- 「查看更多」链接：跳转至帖子浏览页

#### 懒加载策略
- 使用 `IntersectionObserver` 监听容器是否进入视口
- `rootMargin: 200px` 预加载（提前 200px 开始请求）
- 不支持 `IntersectionObserver` 的旧浏览器回退为立即加载

#### 数据来源
- API: `GET /api/stats/boards`
- 返回类型: `Boards { top_likes: BoardTop[], top_replies: BoardTop[] }`
- `BoardTop { fid, name, title, url, value }`

## 三、API 接口汇总

| 接口 | 路径 | 优先级 | 说明 |
|------|------|--------|------|
| 应用配置 | `GET /api/config` | - | 获取自动刷新开关配置 |
| **数据总览** | `GET /api/stats/overview` | P0 | 累计统计、今日/昨日/近7日、用户数 |
| **趋势** | `GET /api/stats/trend?days=N` | P0 | 每日新增帖子数（7/30/90 天） |
| **版块分布** | `GET /api/stats/fid_dist` | P0 | 各版块帖子数分布 |
| **热门榜** | `GET /api/stats/boards` | P1 | 各版块点赞/回复最高帖 |
| 最近抓取 | `GET /api/stats/recent?limit=N` | - | 最新帖子列表 |

### 后端响应结构

#### Overview（`/stats/overview`）
```typescript
interface Overview {
  total: number            // 累计帖子总数
  today: number            // 今日新增
  yesterday: number        // 昨日新增
  week_new: number         // 近 7 日新增
  latest_created_at: string | null  // 最新抓取时间
  latest_date: string | null       // 最新帖子日期
  today_str: string        // 今日日期字符串
  total_users: number      // 累计用户（去重作者数）
  active_users: number     // 今日活跃用户
}
```

#### TrendPoint（`/stats/trend`）
```typescript
interface TrendPoint {
  date: string    // 日期 YYYY-MM-DD
  count: number   // 当日新增帖子数
}
```

#### FidDistItem（`/stats/fid_dist`）
```typescript
interface FidDistItem {
  fid: string              // 版块 ID
  name: string             // 版块名称
  count: number            // 帖子总数
  latest_date?: string | null  // 最新抓取日期
  today_count?: number     // 今日新增
  yesterday_count?: number // 昨日新增
}
```

#### Boards（`/stats/boards`）
```typescript
interface Boards {
  top_likes: BoardTop[]    // 各版块点赞最高帖
  top_replies: BoardTop[]  // 各版块回复最高帖
}

interface BoardTop {
  fid: string       // 版块 ID
  name: string      // 版块名称
  title: string     // 帖子标题
  url: string       // 帖子链接
  value: string     // 点赞/回复数
}
```

## 四、加载策略

### P0 / P1 分区

| 分区 | 区块 | 加载时机 | 加载方式 |
|------|------|----------|----------|
| **P0** | KPI 指标卡 | 页面挂载立即加载 | `Promise.all` 并行请求 |
| **P0** | 每日新增趋势图 | 页面挂载立即加载 | 与 P0 其他区块并行 |
| **P0** | 版块分布（排行榜 + 环形图） | 页面挂载立即加载 | 与 P0 其他区块并行 |
| **P1** | 热门榜（点赞榜 + 回复榜） | 滚动进入视口时加载 | `IntersectionObserver` 懒加载 |

### 加载流程
```
页面挂载
  │
  ├── P0: loadP0(true)
  │     ├── Promise.all([overview, trend(7), fidDist])
  │     ├── 渲染趋势图 + 分布图
  │     ├── 启动环形图轮播 + 排行榜轮播
  │     └── 启动趋势 tooltip 轮播（延迟等待描线动画完成）
  │
  └── P1: IntersectionObserver 监听
        └── 进入视口（rootMargin: 200px）
              └── loadBoards() → 渲染热门榜
```

### 骨架屏占位
- P0 加载时：6 个 KPI 卡片各显示 `el-skeleton`，图表区域显示 8 行骨架
- P1 加载时：热门榜各卡片显示 4 条骨架占位

## 五、自动刷新机制

### 配置
- **默认间隔**: 30 秒（`REFRESH_INTERVAL = 30000`）
- **默认状态**: 由后端配置 `enable_auto_refresh` 决定（后端可通过 `config.ENABLE_AUTO_REFRESH` 控制）
- **Store**: 使用 Pinia `useDashboardStore` 管理全局状态

### 刷新策略
- **仅刷新已加载的区块**：懒加载区块未进入视口时保持不动
- **静默刷新**：不显示 loading 遮罩，在后台静默更新数据
- **数据更新平滑过渡**：图表使用 ECharts 动画实现平滑过渡

### Store 状态
```typescript
// dashboard store
const enableAutoRefresh = ref(false)   // 后端配置总开关
const autoRefresh = ref(false)         // 前端用户开关
const updatedAtRaw = ref<string | null>(null)  // 最后更新时间
```

## 六、技术实现要点

### 关键组件
| 组件 | 文件 | 用途 |
|------|------|------|
| `DashboardView.vue` | `views/DashboardView.vue` | 数据总览主页面 |

### 动态效果汇总

| 效果 | 区块 | 实现方式 |
|------|------|----------|
| **数字滚动** | KPI 指标卡 | `RollingNumber` 组件 |
| **折线入场动画** | 趋势图 | ECharts `animationDelay` 逐点描线 |
| **Tooltip 自动轮播** | 趋势图 | `setInterval` 模拟鼠标悬停 dispatch |
| **版块高亮轮播** | 环形图 | `setInterval` + `dispatchAction({ highlight/downplay })` |
| **排行榜滚动轮播** | 排行榜 | `setInterval` + `scrollTop` 平滑滚动 |
| **维度切换淡入淡出** | 趋势图 | `opacity` CSS transition 300ms |
| **卡片悬停效果** | 热门榜/排行榜 | CSS `:hover` 背景色过渡 |

### 响应式断点
| 断点 | 适配行为 |
|------|----------|
| `≥ 1440px`（大屏） | 环形图图例右侧纵向，中心位置偏左 |
| `≥ 1100px` | 图表左右 1:1 并列 |
| `< 1100px` | 图表上下单列，排行榜隐藏副指标列 |

### 数据交互链路

```
环形图/排行榜 点击 → goDist(fid) → router.push('/posts?fid=xx')
                                        ↓
                              PostsView 接收 route.query.fid
                                        ↓
                              自动预选该版块进行筛选
```

## 七、后端数据支持

### 数据库
- SQLite（WAL 模式）
- 数据库文件：`db/posts.db`

### 缓存策略
| 缓存键 | TTL | 说明 |
|--------|-----|------|
| `overview_v2` | 60s | 总览统计 |
| `fid_dist_v2` | 60s | 版块分布 |
| `boards` | 60s | 热门榜 |
| `fid_meta` | 60s | 版块元数据 |

### 性能优化（已实施）
1. **`_board_top` 改写**：由窗口函数全表扫描改为 per-fid 循环 + `ORDER BY ... LIMIT 1`，命中表达式索引
2. **新增索引**：`idx_posts_likes_expr`、`idx_posts_replies_expr`、`idx_posts_author`、`idx_posts_created_at`
3. **P1 懒加载**：热门榜区块使用 `IntersectionObserver` 延迟加载
4. **缓存复用**：统计类接口统一使用 `db.cached()` 60 秒 TTL 缓存
