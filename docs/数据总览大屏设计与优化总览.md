## 一、页面布局与信息模块

页面分区加载：P0（首屏立即加载）+ P1（视口懒加载，`IntersectionObserver`，`rootMargin: 200px`）。

```
Header（Logo + 导航 + 更新时间 + 自动刷新开关 + 全屏B沉浸）
├─ ① 4 张 KPI 指标卡（横排，主指标 + 副指标双层）
├─ ② 每日新增趋势图（拆分为「总版块」+「各版块」两张并排，各 1/2 宽）
│     · 总版块：7/14/21/28 天切换（下拉可见 + 自动轮播）
│     · 各版块：Top8 版块多系列折线，天数由总版块联动
├─ ③ 版块分布（左右 1:1）：排行榜（轮播） + 环形图（轮播，双击中心可暂停）
└─ ④ 热门榜（P1 懒加载，4 栏）：点赞最高帖 / 回复最高帖 / 今日新增版块 / 今日热议帖
```

### 1.1 KPI 指标卡（4 张，2026-08-27 命名贴合后）

历史沿革：原 7 张合并为 4 张（合并记录见 git 历史）；2026-08-27 随发布时间口径变更整体改名。

| 卡片 | 主指标 | 副指标 | 数据来源 |
|---|---|---|---|
| 累计收录 | `total`（库内标题去重收录量） | 近7日发布 +`week_new` · 覆盖 `fidDist.length` 个版块 | `/stats/overview` + 前端 `fid_dist` |
| 今日发布 | `today`（按真实发布日统计） | 较昨日环比 ↑/↓% · 昨日 `yesterday` | 计算 |
| 发帖作者 | `total_users`（author 去重） | 今日更新 `active_users` 人 · 活跃率 % | `/stats/overview` |
| 最近入库 | 最近批次日期（`latest_run_at` 取 MM-DD） | 今天/昨天/N 天前 · 批次 HH:MM · 抓取中徽标 | `overview.latest_run_at` + `/api/runs` |

### 1.2 每日新增趋势图

- 已拆分为「总版块」+「各版块」双图并排，实现**双向 Tooltip 联动**、悬停暂停自动轮播。
- 总版块保留：σ 区间带（markArea）、日均虚线（markLine）、峰谷脉冲（effectScatter）、折线流光（CSS shine）、数字滚动（RollingNumber）。
- 维度轮播序列 `TREND_DAYS_SEQ=[7,14,21,28]`；数据点 >31 时启用 DataZoom。

### 1.3 版块分布 · 排行榜

- 固定可视区 8 行 × 40px，每 2000ms 平滑上滚轮播（末尾补位无缝循环）。
- 行：`[名次徽章] [版块名(fid)] [今日新增/最新] [总量条数(占比)]`；前 3 名金/银/铜渐变徽章。
- 交互：悬停暂停轮播、点击行 `goPostsWith({fid})` 下钻帖子浏览；tooltip 显示最近抓取/今日/昨日。

### 1.4 版块分布 · 环形图

- 内外半径 42%~68%，确定性 13 色色板（与排行榜同色）；占比 ≥4% 显示外部标签。
- 每 2200ms 自动高亮轮播，中心显示当前版块名称/数量/占比；点击扇区/图例 `goPostsWith({fid})` 下钻。

### 1.5 热门榜（4 栏，P1 懒加载）

数据来自 `/stats/boards`（点赞/回复最高帖）+ `/stats/today_top_fids`（今日新增版块 Top）+ `/stats/rising`（今日热议帖，今日新增帖中 `likes+replies` 最高 Top）。

交互规则（2026-08-26 调整）：
- **点赞最高帖 / 回复最高帖**：标题点击 → `window.open` 原帖 URL（新标签）；卡片空白区点击 → 下钻该版块（`/posts?fid=&sort=likes_desc|replies_desc`）；「查看更多」→ 带排序下钻帖子浏览（`/posts?sort=likes_desc` / `/posts?sort=replies_desc`）。
- **今日新增版块 / 今日热议帖**：标题/卡片点击 → 下钻帖子浏览（带 `fid` 或关键词）。

## 二、API 接口与后端支持

| 接口 | 路径 | 优先级 | 说明 |
|---|---|---|---|
| 应用配置 | `GET /api/config` | - | 自动刷新开关 |
| 数据总览 | `GET /api/stats/overview` | P0 | 累计/今日/昨日/近7日/用户数 |
| 趋势 | `GET /api/stats/trend?days=N` | P0 | 每日新增（7/14/21/28 天，可下钻各版块 `trend_by_fid`） |
| 版块分布 | `GET /api/stats/fid_dist` | P0 | 各版块帖子分布 |
| 热门榜 | `GET /api/stats/boards` | P1 | 各版块点赞/回复最高帖 |
| 今日新增版块 | `GET /api/stats/today_top_fids?top=6` | P1 | 当日新增帖最多版块 Top |
| 今日热议帖 | `GET /api/stats/rising?limit=8` | P1 | 当日互动量(likes+replies)最高帖 |
| 最近抓取 | `GET /api/stats/recent?limit=N` | - | 最新帖子列表 |

- **数据库**：SQLite（WAL），`db/posts.db`；统计接口统一 `db.cached()` 5s TTL。
- **性能优化**：`_board_top` 改 per-fid `ORDER BY ... LIMIT 1` 命中表达式索引；新增 `idx_posts_likes_expr` / `idx_posts_replies_expr` / `idx_posts_author` / `idx_posts_created_at`；P1 懒加载减少首屏压力。

## 三、加载与刷新

- **P0**：`Promise.all([overview, trend(7), fidDist])` 并行；渲染后启动环形图轮播、排行榜轮播、趋势 Tooltip 轮播。
- **P1**：`IntersectionObserver`（rootMargin 200px）进入视口才 `loadBoards()`。
- **自动刷新**：默认 5s（`REFRESH_INTERVAL=5000`），由 `useDashboardStore` 管理；仅静默刷新已加载区块，不显示遮罩。
- **骨架屏**：P0 时 KPI/图表骨架占位；P1 时热门榜骨架。

## 九、2026-08-27 发布时间口径与命名调整（已落地）

1. **入库口径**：`posts.created_at` = 帖子真实发布时间戳（Unix 秒，来自 HTML `data-timestamp` 去尾 `s`）；`posts.date` = 由该时间戳派生的真实发布日；upsert 冲突时两列随真值覆盖（存量自愈）。详见《帖子发布时间提取入库优化方案.md》。
2. **新鲜度数据源**：`/stats/overview` 新增 `latest_run_at`（run_days 最近批次的开始/结束时刻较大者）；「最近入库」卡与 Header「更新于」均以入库活动时间为准，跑批即时反映，不再受发布日口径影响。
3. **命名贴合（N1-N8）**：累计帖子→**累计收录**、今日新增→**今日发布**、累计作者→**发帖作者**（副值「今日更新 N 人」）、数据新鲜度→**最近入库**、趋势 tooltip/系列名→**发布**口径、今日最热→**最新最热**（日期角标保留）。N7（排行榜今日新增列）/N9（今日新增版块）在当前页面无对应文案，未涉及。
4. **B1 抓取中徽标**：批次运行时「最近入库」卡副值显示绿色脉冲「抓取中 N%」（数据源 `/api/runs` running 记录实时聚合进度），结束后回落为"今天/昨天/N 天前"；`loadP0` 顺带轮询，失败静默置空不影响总览。
5. **孤儿 running 三层防护**（2026-08-27）：批次被外部强杀/崩溃时 `finish_run` 无法执行，`run_days` 残留 running 孤儿行导致徽标常亮。三层修复：写侧心跳（`run_recorder.update_section` 顺带刷新 `run_days.updated_at`）、启动收编（`start_run` 前将历史 running 收编为 error）、读侧降级（`web/runs.py` 对超过 `RUNNING_STALE_SECONDS=1800` 无心跳的 running 仅展示降级为 error，不写库）。阈值基于最后心跳而非开始时刻（正常批次实测 27-28 分钟持续有心跳，不会误杀）。
6. B2 KPI 下钻 / B3 滞后警示 / B4 空窗文案：本次未选，留作候选。
