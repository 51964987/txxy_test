### 1.5 热门榜（4 栏，P1 懒加载）

数据来自 `/stats/boards`（点赞/回复最高帖）+ `/stats/today_top`（最新最热：最新数据日期内点赞+回复综合 Top）+ `/stats/month_top`（本月最热：最新数据月份内综合 Top）。原「今日新增版块 / 今日热议帖」两栏已于 2026-08-28 替换为「最新最热 / 本月最热」。

交互规则（2026-08-26 调整，2026-08-28 增补）：
- **点赞最高帖 / 回复最高帖**：标题点击 → `window.open` 原帖 URL（新标签）；卡片空白区点击 → 下钻该版块（`/posts?fid=&sort=likes_desc|replies_desc`）；「查看更多」→ 带排序下钻帖子浏览（`/posts?sort=likes_desc` / `/posts?sort=replies_desc`）。
- **最新最热 / 本月最热**（2026-09-01 补下钻与口径展示）：标题点击打开原帖 URL；**卡片空白区点击 → 下钻「该版块 + 该时间窗」**（`/posts?fid=&date_from=&date_to=&sort=engagement_desc`）；「查看更多」→ 下钻整个时间窗（最新最热=最新数据日当天，本月最热=最新数据月份的月初~月末）。每行主指标显示**互动量（点赞+回复）**——这是榜单的排序依据，此前只显示分开的点赞/回复，会出现「第 2 名点赞更多却排在后面」的困惑；点赞/回复明细进 tooltip。本月最热额外显示发布日（MM-DD），最新最热各行都是同一天、展示无信息量故不渲染。
- **每行悬浮「下载」按钮**：直接 `POST /api/downloads` 创建下载任务（`@click.stop.prevent` 阻断卡片跳转），进度在下载中心查看。

### 1.6 活跃作者 Top10 / 活跃版块 Top10（2026-08-28 上线，2026-09-01 加口径与环比）

- 左右 1:1 横向条形图，P0 随首屏加载（`/stats/top_authors`、`/stats/top_fids`）。
- 作者条点击 → 帖子浏览按作者精确过滤（`/posts?author=`）；版块条点击 → 跳该版块列表；颜色：作者多色区分，版块按 `FID_PALETTE` 确定性色板。
- **下钻继承统计口径**（2026-09-01）：下钻时按当前口径附带 `date_from` / `date_to`（`all` 口径不传，即看全部），使榜单数字与帖子页结果自洽——在「近 7 日」榜上看到 431 条，点进去就是这 431 条，而不是该作者全部的 4314 条。帖子页顶部「当前条件」摘要条展示全部生效条件，可逐项清除或清空全部。
- **统计口径可切换**（2026-09-01）：卡片右上角 `累计 / 近 7 日 / 近 30 日` 分段控件，两卡独立记忆，切换只重新拉取对应榜单，不整页刷新。

| 口径 | 排序与主值 | 候选范围 |
|---|---|---|
| 累计（默认） | `total` | 全部 |
| 近 7 日 | `week` | 仅近 7 日有发帖（`HAVING week_c > 0`） |
| 近 30 日 | `month` | 仅近 30 日有发帖（`HAVING month_c > 0`） |

> 非累计口径必须加 `HAVING` 过滤，否则榜单会被大量 0 值占满，切换后看起来毫无变化。
> 口径切换确实会改变排名：实测累计第 2 名的作者近 7 日只有 234 条，被 431 条的作者反超。

- **环比展示**（2026-09-01）：近 7 日 vs 前 7 日（第 8~14 天）的涨跌百分比，`delta` 字段：
  - 条尾随主值一并展示，涨绿 `↑x%` / 跌红 `↓x%` / 持平灰 `持平`；
  - 前 7 日为 0 时无计算基准，`delta=null`，按橙色「新增」展示。
- **文案统一**：两卡副标题同构 —— `按<口径>发帖量 · 点击查看该<作者|版块>帖子`。
- **空态**：某口径下无数据时显示「该时间段暂无数据」，不再是空白区。
- **实现要点**：图表复用「数据指纹跳过重绘」机制，指纹已纳入口径（`name:value:valueLabel`），否则切换口径后数值未变时图表不会刷新。

## 二、API 接口与后端支持

| 接口 | 路径 | 优先级 | 说明 |
|---|---|---|---|
| 应用配置 | `GET /api/config` | - | 自动刷新开关 |
| 数据总览 | `GET /api/stats/overview` | P0 | 累计/今日/昨日/近7日/用户数 + `latest_run_at`（入库活动时间，新鲜度依据） |
| 趋势 | `GET /api/stats/trend?days=N` | P0 | 每日发布趋势（7/14/21/28 天，联动各版块 `trend_by_fid`） |
| 版块分布 | `GET /api/stats/fid_dist` | P0 | KPI 副指标「覆盖 N 个版块」（版块分布图已移除，接口保留） |
| 活跃作者榜 | `GET /api/stats/top_authors?limit=10&range=all` | P0 | `range=all\|7d\|30d` 切换统计口径（非法值 422）；返回 `total/today/week/month/prev_week/delta/value`，`value` 为当前口径主值 |
| 活跃版块榜 | `GET /api/stats/top_fids?limit=10&range=all` | P0 | 与作者榜同构（`range` 语义相同） |
| 热门榜 | `GET /api/stats/boards` | P1 | 各版块点赞/回复最高帖 |
| 最新最热 | `GET /api/stats/today_top?limit=10` | P1 | 最新数据日期内互动量(likes+replies)最高帖；返回 `total`（当日帖数）/ `days`（=1）供卡头说明样本规模 |
| 本月最热 | `GET /api/stats/month_top?limit=10` | P1 | 最新数据月份内互动量最高帖；返回 `total`（当月帖数）/ `days`（当月已入库天数，`<7` 时提示样本较少） |
| 运行记录 | `GET /api/runs` | - | 「抓取中」徽标实时进度（B1） |
| 最近帖子 | `GET /api/stats/recent?limit=N` | - | 最新帖子列表（前端当前未使用，接口保留） |

> 历史更名：`today_top_fids` → `today_fids`、`rising` → `today_top`（旧文档中的接口名，现均已按右列名称提供）；`today_fids` 与 `recent` 前端当前未使用，接口保留。

- **数据库**：SQLite（WAL），`db/posts.db`；统计接口统一 `db.cached()` 5s TTL。
- **性能优化**：`_board_top` 改 per-fid `ORDER BY ... LIMIT 1` 命中表达式索引；新增 `idx_posts_likes_expr` / `idx_posts_replies_expr` / `idx_posts_author` / `idx_posts_created_at`；P1 懒加载减少首屏压力。

## 三、加载与刷新

- **P0**：`Promise.all([overview, trend, fidDist, topAuthors, topFids])` 并行；渲染后启动趋势 Tooltip 轮播；「分版块发布对比」滚动进入视口后懒加载 `trend_by_fid`。
- **P1**：`IntersectionObserver`（rootMargin 200px）进入视口才 `loadBoards()`（`boards` + `today_top` + `month_top` 并行）。
- **自动刷新**：默认 5s（`REFRESH_INTERVAL=5000`），由 `useDashboardStore` 管理；仅静默刷新已加载区块，不显示遮罩。
- **骨架屏**：P0 时 KPI/图表骨架占位；P1 时热门榜骨架。

## 九、2026-08-27 发布时间口径与命名调整（已落地）

1. **入库口径**：`posts.created_at` = 帖子真实发布时间戳（Unix 秒，来自 HTML `data-timestamp` 去尾 `s`）；`posts.date` = 由该时间戳派生的真实发布日；upsert 冲突时两列随真值覆盖（存量自愈）。详见《帖子发布时间提取入库优化方案.md》。

3. **命名贴合（N1-N8）**：累计帖子→**累计收录**、今日新增→**今日发布**、累计作者→**发帖作者**（副值「今日更新 N 人」）、数据新鲜度→**最近入库**、趋势 tooltip/系列名→**发布**口径、今日最热→**最新最热**（日期角标保留）、总版块→**全站发布趋势**、各版块→**分版块发布对比**（统计卡加 `white-space: nowrap` 防数值折行，挤压时由 `chart-head-right` 的 wrap 整条换行兜底）。N7（排行榜今日新增列）/N9（今日新增版块）在当前页面无对应文案，未涉及。

## 十一、2026-09-01 活跃榜口径与环比（已落地）

背景：两个榜名为「活跃」，排序依据却是**累计发帖量**（`ORDER BY total DESC`），反映的其实是历史资历而非当前活跃度——老作者/大版块长期霸榜，榜单几乎不动。

1. **统计口径可切换**：`/api/stats/top_authors`、`/api/stats/top_fids` 新增 `range` 参数（`all` / `7d` / `30d`，默认 `all`，非法值 422）；响应新增 `month`（近 30 日）、`prev_week`（前 7 日）、`delta`（环比）、`value`（当前口径主值）。非累计口径加 `HAVING <口径> > 0`，避免 0 值占满榜单。
2. **环比展示**：近 7 日 vs 前 7 日涨跌百分比，条尾随主值显示（涨绿 / 跌红 / 持平灰 / 新增橙），tooltip 补齐各口径明细（累计·今日·近 7 日·近 30 日）。
3. **前端交互**：卡片右上角分段控件（两卡独立记忆），切换只重拉对应榜单、不整页刷新；图表数据指纹纳入口径，规避「数值未变则不重绘」。
4. **文案与空态**：两卡副标题统一为「按<口径>发帖量 · 点击查看该<作者|版块>帖子」；无数据显示「该时间段暂无数据」。
5. **顺带修复**：SQL 增加 `date >= '2000-01-01'` 过滤——库中存在 1970 年的脏日期（历史解析异常），会污染时间窗口类口径。
6. **下钻继承口径**（同日追加）：`goAuthor` / `goDist` 按当前口径附带 `date_from` / `date_to`；帖子页新增「当前条件」摘要条（版块/作者/关键词/日期，逐项可清除 + 清空全部），日期选择器补「近 7 日 / 近 30 日」快捷项。同时修正一处条件残留：此前在关键词框输入新词后，下钻带来的 `author` 精确条件不会解除，导致「换了关键词却仍被旧作者限制」。
7. **一致性收尾（2026-09-01）**：① 摘要条补「排序」条件——仅非默认排序（非「日期倒序」）时显示，如「排序：点赞数倒序」，可一键还原默认；否则从热门榜按点赞下钻时列表顺序与条件条对不上。② `goPostsWith` 补注释警示：该函数**不带时间语义**，目前仅用于「全站历史最高」类卡片（点赞/回复最高帖），未来若有时间窗口入口复用必须并入 `rankDateRange`，否则重蹈口径不一致。③ 记录潜在坑：最新最热 / 本月最热卡片有明确时间语义（最新数据日期 / 最新数据月份），目前仅打开原帖、无「查看更多」下钻；将来若加下钻必须带对应时间范围（当日 / 当月），否则又是同一类数字矛盾。
8. **最新最热 / 本月最热的维度优化与下钻（2026-09-01，P0 实施）**：① 后端 `_SORTS` 新增 `engagement_desc`（`(CAST(likes)+CAST(replies)) DESC`），排序表达式与 `today_top`/`month_top` 完全一致，使下钻后的列表顺序与榜单一致——此前帖子页只有点赞/回复单维排序，直接下钻必然对不上榜单顺序；前端帖子页同步增加「互动量倒序」选项。② 两卡主指标从「分开显示点赞/回复」改为**互动量**（排序依据显性化，点赞/回复明细进 tooltip），本月最热补发布日（MM-DD），最新最热各行都是同一天、展示无信息量故不渲染。③ 两卡新增交互：卡片空白区下钻「同版块 + 同时间窗」、「查看更多」下钻整个时间窗，与点赞/回复最高帖交互对齐。④ 新增 `goPostsInRange`（带时间窗下钻），与不带时间语义的 `goPostsWith` 分开；时间窗用**接口返回的日期**计算而非当前时间——跨月边界时（今天 9/1 但最新数据还是 8/31）「本月」指的是 8 月。⑤ 卡头角标加口径 tooltip（按数据最新日/月统计、共 N 帖、覆盖 M 天，`days<7` 提示样本较少）。⑥ 两接口返回 `total`/`days`，缓存 key bump 至 `today_top_v2`/`month_top_v2`（否则旧缓存无新字段，前端会显示 0）。
