帖子链接同源中继转发技术报告

本报告针对「让手机 / 局域网设备也能打开本机回环镜像（web.exe @ 127.0.0.1:1024）里的帖子链接」这一需求， 拆解其背后的知识点、技术难点、踩坑点与逐文件实现。所有代码片段均来自项目真实文件，已做 HTML 转义； 标「可独立运行示例」的片段依赖已注明、可直接跑通。

一、项目总览

1.1 背景与问题

项目是单人自用的「站点内容采集 + 本地媒体资产管理」工具。抓取端通过本机镜像 web.exe（仅监听回环地址 127.0.0.1:1024）加速访问站点。 看板展示帖子链接时，某天发现手机打不开帖子页——根因是地址语义：

  • 127.0.0.1 是每台设备自己的回环地址，手机上的 127.0.0.1 指向手机自己；
  • web.exe 实测只绑回环（netstat 为 TCP 127.0.0.1:1024 LISTENING），且其安装目录无任何可改监听地址的配置；
  • 因此「手机访问 http://<桌面IP>:1024/...」在任何配置下都不可能成功——不是配置漏了，是地址语义决定的。

1.2 方案与目标

看板进程本身局域网可达（TXXY_WEB_HOST=0.0.0.0），于是在看板端口上加一条同源反向代理 /mirror 路由：浏览器只访问「看板自己的源」，由看板进程替它去访问那个别人够不着的回环地址。 

手机 → http://<桌面IP>:8088/mirror/htm_data/xxx.html → 转发 → 127.0.0.1:1024/htm_data/xxx.html

1.3 收益

维度说明
链接形态从「写死一个域名/地址」变成相对路径 /mirror/htm_data/...，桌面 / 手机 / 局域网 IP / 将来换域名，前端代码一行都不用因访问方式改
安全面纯代码、零环境配置、复用已放行的 8088、天然带降级钩子，无需把无鉴权的 1024 直接开到局域网
鲁棒性镜像没起来 / 未配置镜像时自动 302 到业务域名同一路径，链接永远打得开

3.1 关键数据流说明

链路触发条件行为
正常转发镜像在跑且返回 < 500看板转发请求，HTML 重写根相对链接、3xx Location 改写、二进制原样透传
降级转发镜像连不上 / 5xx / 本环境无镜像302 到 PUBLIC_DOMAIN + 同一路径（含查询串）
4xx 透传镜像返回 4xx原样返回，不降级——那是镜像给出的真实答案（如页面确实不存在）

四、涉及的知识点总览

知识点在本项目中的落点
网络回环地址语义127.0.0.1 每设备独立；手机访问自己的 127.0.0.1 永远不到桌面
网络绑定 vs 访问用 netstat -ano | findstr ":1024" 判定服务绑在回环还是全网卡（0.0.0.0）
架构反向代理入口与看板同源（host:port），前端不拼域名，等价于 nginx proxy_pass / Vite dev proxy
安全SSRF 防护上游地址写死取自唯一配置源 txxy_env.LOCAL_PROXY，绝不接受调用方传入
前端同源策略 / 相对路径链接用 /mirror/... 相对路径，天然规避跨域
WebHTML 链接重写静态属性（href/src/action）+ 运行时 JS 生成链接的点击兜底脚本
HTTPRange / Content-Encoding转发必须保留 Content-Encoding 与 Content-Length，否则浏览器解压/分段失败
HTTPHEAD 兼容上游不支持 HEAD 时改用 GET 取头、按 HEAD 语义只回头
路由SPA 兜底顺序中继路由须注册在 SPA 兜底路由之前，否则被当成页面路由
架构单一 owner镜像进程谁启动谁关闭；看板退出须确认无批次在跑
工程配置单一源域名 / 镜像地址只定义在 txxy_env.py，地址即开关（置空即关）
运维环境自适应本地 Windows 启用镜像、Docker/Linux 自动跳过（无 web.exe）

五、技术难点总览与踩坑点

5.1 中继实现的 8 个要点（难点）

#难点正解
1上游地址写死防 SSRF只取自 txxy_env.LOCAL_PROXY，不接受调用方传入地址
2降级策略连不上 / 5xx → 302 同路径；4xx 透传（真实答案）
3HTML 两类链接重写静态属性重写 + 运行时 JS 链接点击兜底（只做静态会留下「看得见点不通」的链接）
43xx Location 改写镜像指回 127.0.0.1:1024，不改写浏览器会去打够不着的地址
5二进制透传三坑① 用 raw.read 而非 iter_content（后者解压）；② Content-Length/Range 须准确；③ 不透传逐跳头
6HEAD 兼容上游不支持 HEAD（实测 404）→ 改用 GET 取头、只回头不读体
7SPA 兜底路由顺序中继路由注册在兜底路由之前
8限流要单独想一次页面十余次子资源请求，按 (IP,路径) 限流必误伤 → 中继不挂限流

5.2 踩坑清单（都实际踩过）

坑现象正解
iter_content 解压透传 Content-Encoding/Length 时浏览器解析失败用 raw.read 产出原始字节
只重写静态链接「看得见、点不通」的链接（JS 运行时生成）追加点击瞬间兜底脚本
SPA 兜底吃掉 /mirror打开链接变成看板首页路由注册在兜底路由之前
atexit 里 import 新模块RuntimeError: can't register atexit after shutdown，镜像没关掉残留依赖模块启动期预加载（_preload_batch_lock）
改 .bat 三硬约束行尾 LF / 中文落引号 / 全角结尾吞下一行保持 CRLF；中文只放 echo 行；非 echo 行 ASCII 结尾
启动器继承外部 PYTHONPATHIDE 注入的 sitecustomize 在删除接口抛 SystemExit，带崩看板启动器清空 PYTHONPATH；运行时告警并摘掉

mirror_demo.py
"""帖子链接同源中继 —— 可独立运行的最小示例。
依赖: fastapi, uvicorn, requests（pip install fastapi uvicorn requests）
环境变量（均从环境变量读取，不硬编码密钥）:
  MIRROR_UPSTREAM  上游镜像地址，默认 http://127.0.0.1:1024；置空=无镜像直接降级
  MIRROR_PUBLIC    业务域名，默认 https://txxy.com
  MIRROR_LISTEN    中继监听 host:port，默认 127.0.0.1:8088
"""
from collections.abc import Iterator
import os
import re

import requests
from fastapi import APIRouter, FastAPI, Request
from fastapi.responses import RedirectResponse, Response, StreamingResponse

# ---- 配置（只从环境变量读，地址即开关：置空即关闭，符合项目唯一配置源约定）----
MIRROR_PREFIX: str = "/mirror"
MIRROR_UPSTREAM: str = os.getenv("MIRROR_UPSTREAM", "http://127.0.0.1:1024").rstrip("/")
MIRROR_PUBLIC: str = os.getenv("MIRROR_PUBLIC", "https://txxy.com").rstrip("/")
MIRROR_LISTEN: str = os.getenv("MIRROR_LISTEN", "127.0.0.1:8088")

# 响应头透传白名单：只转发与内容语义相关的头；逐跳头与安全头一律不透传
_PASS_RESP_HEADERS: frozenset[str] = frozenset({
    "content-type", "content-length", "content-range", "accept-ranges",
    "last-modified", "etag", "content-encoding", "cache-control",
    "expires", "content-disposition", "vary",
})
# 请求头透传：Range 保留视频拖动；Cookie 保留桌面端在镜像上的登录态
_PASS_REQ_HEADERS: tuple[tuple[str, str], ...] = (
    ("range", "Range"),
    ("if-none-match", "If-None-Match"),
    ("if-modified-since", "If-Modified-Since"),
    ("cookie", "Cookie"),
)
# 根相对属性正则：href="/x" 命中；href="//host/x"(协议相对) 与 href="#" 不命中
_ROOT_ATTR_RE: re.Pattern[str] = re.compile(
    r"""(\b(?:href|src|action)\s*=\s*["'])/(?!/)""", re.I
)
_CHARSET_RE: re.Pattern[str] = re.compile(r"charset=([\w-]+)", re.I)

PROJECT_UA: str = "txxy-agent/1.0"  # 全项目唯一 UA（此处为示例占位）


def _fallback_url(path: str, query: str) -> str:
    """降级目标：业务域名 + 同一路径（查询串原样带上，避免二次编码）。"""
    url: str = f"{MIRROR_PUBLIC}/{path.lstrip('/')}"
    return f"{url}?{query}" if query else url


def _upstream_headers(request: Request, upstream: str) -> dict[str, str]:
    """构造发往镜像的请求头：UA 用项目唯一 UA，透传浏览器 Accept 与 Range/Cookie。"""
    headers: dict[str, str] = {"User-Agent": PROJECT_UA}
    accept: str | None = request.headers.get("accept")
    if accept:
        headers["Accept"] = accept
    for src, dst in _PASS_REQ_HEADERS:
        value: str | None = request.headers.get(src)
        if value:
            headers[dst] = value
    headers["Referer"] = upstream + "/"  # 同源来源，防防盗链
    return headers


def _rewrite_location(location: str, upstream: str) -> str:
    """镜像返回的 Location 改写回中继前缀；站外跳转原样返回。"""
    if location.startswith(upstream):
        return MIRROR_PREFIX + location[len(upstream):]
    return location


def _rewrite_html(text: str) -> str:
    """HTML 重写：根相对属性指回中继前缀 + 追加点击时兜底脚本（覆盖 JS 运行时生成的链接）。"""
    out: str = _ROOT_ATTR_RE.sub(lambda m: f"{m.group(1)}{MIRROR_PREFIX}/", text)
    script: str = (
        "<script>(function(){document.addEventListener('click',function(e){"
        "var t=e.target;var a=t&&t.closest?t.closest('a[href]'):null;if(!a)return;"
        "var h=a.getAttribute('href')||'';"
        "if(h.charAt(0)!=='/'||h.charAt(1)==='/')return;"
        "if(h.indexOf('" + MIRROR_PREFIX + "/')===0)return;"
        "a.setAttribute('href','" + MIRROR_PREFIX + "'+h);},true);})();</script>"
    )
    if re.search(r"</body>", out, re.I):
        return re.sub(r"</body>", script + "</body>", out, count=1, flags=re.I)
    return out + script


def _iter_raw(up: requests.Response, chunk: int = 64 * 1024) -> Iterator[bytes]:
    """逐块产出原始字节（不自动解压）：绕开 iter_content，避免解压后与保留的头冲突。"""
    try:
        while True:
            piece: bytes = up.raw.read(chunk) if up.raw is not None else b""
            if not piece:
                break
            yield piece
    finally:
        up.close()


router: APIRouter = APIRouter()


@router.api_route(MIRROR_PREFIX + "/{path:path}", methods=["GET", "HEAD"],
                  include_in_schema=False)
def mirror(path: str, request: Request) -> Response:
    """转发到本地镜像；镜像访问不了时降级到业务域名同一路径。"""
    query: str = request.url.query
    upstream: str = MIRROR_UPSTREAM
    if not upstream:  # 本环境没有本地镜像（Docker / 离线）：直接交给业务域名
        return RedirectResponse(_fallback_url(path, query), status_code=302)

    target: str = f"{upstream}/{path}"
    if query:
        target = f"{target}?{query}"
    # 上游对 HEAD 不支持（实测 404）：统一用 GET 取头，下面按 HEAD 语义只回头
    upstream_method: str = "GET" if request.method == "HEAD" else request.method
    try:
        up: requests.Response = requests.request(
            upstream_method, target,
            headers=_upstream_headers(request, upstream),
            stream=True, timeout=(3, 30),
            allow_redirects=False,  # 自行处理 Location 改写
        )
    except requests.RequestException:
        return RedirectResponse(_fallback_url(path, query), status_code=302)

    status: int = up.status_code
    ctype: str = up.headers.get("content-type", "")
    location: str = up.headers.get("location", "")

    if 300 <= status < 400 and location:
        up.close()
        return RedirectResponse(_rewrite_location(location, upstream), status_code=status)
    if status >= 500:  # 镜像坏了：降级比把 500 透给用户更有用
        up.close()
        return RedirectResponse(_fallback_url(path, query), status_code=302)

    passthrough: dict[str, str] = {
        k: v for k, v in up.headers.items() if k.lower() in _PASS_RESP_HEADERS
    }
    set_cookies: list[str] = up.raw.headers.getlist("set-cookie") if up.raw is not None else []

    if request.method == "HEAD":
        up.close()
        resp: Response = Response(status_code=status, headers=passthrough)
    elif "text/html" in ctype.lower():
        body: bytes = up.content  # 缓冲（自动解压）后重写；随后 content-length/encoding 失效
        up.close()
        charset = _CHARSET_RE.search(ctype)
        text: str = body.decode(charset.group(1) if charset else "utf-8", errors="replace")
        out_bytes: bytes = _rewrite_html(text).encode("utf-8")
        heads: dict[str, str] = {
            k: v for k, v in passthrough.items()
            if k.lower() not in ("content-length", "content-encoding", "content-type")
        }
        resp = Response(content=out_bytes, status_code=status, headers=heads,
                        media_type=ctype or "text/html; charset=utf-8")
    else:
        resp = StreamingResponse(_iter_raw(up), status_code=status, headers=passthrough)

    for cookie in set_cookies:
        resp.headers.append("set-cookie", cookie)
    return resp


app: FastAPI = FastAPI()
app.include_router(router)  # 生产环境须注册在 SPA 兜底路由之前


if __name__ == "__main__":
    import uvicorn
    host, _, port = MIRROR_LISTEN.partition(":")
    uvicorn.run(app, host=host, port=int(port))

6.4 web/frontend/src/utils/postUrl.ts —— 前端拼装唯一实现

核心逻辑：所有「打开 / 复制帖子链接」都走这里；打开用 /mirror 相对路径、复制用同源绝对地址。降级由后端处理，前端恒用中继前缀。

postUrl.ts
/** 同源中继前缀：与后端 web/mirror.py 的路由约定，改一处必须同步改另一处 */
export const MIRROR_PREFIX = '/mirror'

/** 本站帖子路径标记：用于把「带域名的完整地址」归一成站点相对路径 */
const SITE_PATH_MARK = '/htm_data/'

/** 取本站帖子的相对路径（含查询串）；站外链接返回空串 */
export function postPathOf(url: string): string {
  const i = url.indexOf(SITE_PATH_MARK)
  return i >= 0 ? url.slice(i) : ''
}

/** 打开用：本站帖子 → 同源中继相对路径；站外链接原样返回 */
export function postOpenUrl(url: string): string {
  const path = postPathOf(url)
  return path ? MIRROR_PREFIX + path : url
}

/** 复制用：同源绝对地址（粘到本机或局域网其它设备都能打开） */
export function postCopyUrl(url: string): string {
  const path = postPathOf(url)
  return path ? new URL(MIRROR_PREFIX + path, window.location.origin).href : url
}

6.6 mirror_service.py —— 1024 镜像端口守护（单一 owner）

核心逻辑：探测端口 → 未监听则启动 web.exe（注入回车触发静默启动）并等待就绪 → 关闭时只关自己启动的那一个。供 run_batch.py 与 start_web.py 共用，遵循「谁启动谁关闭」。

6.6.1 可直接运行的最小示例（仅依赖标准库）

运行方式：python mirror_guard_demo.py。它会启动一个本地 http.server 作为「假上游」演示端口探测 / 等待就绪 / 关闭；生产环境把 WEB_APP_EXE 换成真实 web.exe 路径即可。无第三方依赖。
mirror_guard_demo.py
"""1024 本地镜像端口守护 —— 可独立运行的最小示例（仅依赖标准库）。
演示：端口探测、等待就绪、谁启动谁关闭（单一 owner）。
生产环境把 WEB_APP_EXE 换成真实 web.exe 路径、用 subprocess.Popen([WEB_APP_EXE], ...)
并注入回车触发其静默启动即可（见项目 mirror_service.py）。
"""
import http.server
import socketserver
import subprocess
import sys
import threading
import time
from urllib.parse import urlparse

WEB_HOST: str = "127.0.0.1"
WEB_PORT: int = 1024
WEB_APP_START_TIMEOUT: float = 15.0
WEB_APP_SHUTDOWN_TIMEOUT: float = 10.0


def is_port_listening(port: int, host: str = WEB_HOST) -> bool:
    """检测 host:port 是否已可建立 TCP 连接。"""
    import socket
    try:
        with socket.create_connection((host, port), timeout=1.0):
            return True
    except OSError:
        return False


def wait_port_ready(port: int, timeout: float) -> bool:
    """轮询等待端口变为可连接，超时返回 False。"""
    deadline: float = time.time() + timeout
    while time.time() < deadline:
        if is_port_listening(port):
            return True
        time.sleep(0.5)
    return False


def wait_port_closed(port: int, timeout: float) -> bool:
    """轮询等待端口被释放，超时返回 False。"""
    deadline: float = time.time() + timeout
    while time.time() < deadline:
        if not is_port_listening(port):
            return True
        time.sleep(0.5)
    return False


def _start_fake_upstream() -> "subprocess.Popen[bytes] | None":
    """演示用：启动一个本地 http.server 充当「假镜像」；生产替换为 web.exe。"""
    handler = http.server.SimpleHTTPRequestHandler
    # 在独立线程里起服务，避免阻塞主线程
    srv = socketserver.TCPServer((WEB_HOST, WEB_PORT), handler)
    t = threading.Thread(target=srv.serve_forever, daemon=True)
    t.start()
    return None  # 演示：这里用线程内服务模拟，关闭由下方 wait_port_closed 判定


def ensure_web_service() -> bool:
    """确保端口已监听（演示版：已监听返回 False 表示「外部占用，只消费不关闭」）。"""
    if is_port_listening(WEB_PORT):
        print(f"[1024服务] 端口 {WEB_HOST}:{WEB_PORT} 已被监听，跳过启动")
        return False
    print(f"[1024服务] 启动假上游（生产为 web.exe）...")
    _start_fake_upstream()
    if not wait_port_ready(WEB_PORT, WEB_APP_START_TIMEOUT):
        raise RuntimeError(f"启动后 {WEB_APP_START_TIMEOUT}s 内端口仍未就绪")
    print(f"[1024服务] 端口 {WEB_HOST}:{WEB_PORT} 就绪")
    return True


def shutdown_web_service(owned: bool) -> None:
    """关闭：非本次启动的进程跳过（单一 owner 原则）。"""
    if not owned:
        print(f"[1024服务] 端口由外部占用（非本次启动），跳过关闭")
        return
    print(f"[1024服务] 正在关闭...")
    # 生产：proc.terminate() + 兜底 netstat 定位 PID 强杀；演示直接等端口释放
    if wait_port_closed(WEB_PORT, WEB_APP_SHUTDOWN_TIMEOUT):
        print(f"[1024服务] 端口 {WEB_HOST}:{WEB_PORT} 已释放")


if __name__ == "__main__":
    owned = ensure_web_service()
    try:
        time.sleep(2)  # 模拟看板/批次运行期间
    finally:
        shutdown_web_service(owned)
    print("演示结束。")

def ensure_web_service() -> "subprocess.Popen[bytes] | None":
    """确保 web.exe 已监听 WEB_PORT。端口已被监听返回 None（非本模块启动，调用方不应关闭）。"""
    if is_port_listening(WEB_PORT):
        return None
    if not os.path.exists(WEB_APP_EXE):
        raise RuntimeError(f"web.exe 不存在: {WEB_APP_EXE}")
    # web.exe 是 PyInstaller 交互式控制台程序：必须注入回车才会真正开始监听
    proc = subprocess.Popen([WEB_APP_EXE], stdin=subprocess.PIPE,
                            stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL,
                            cwd=os.path.dirname(WEB_APP_EXE),
                            creationflags=_CREATE_NO_WINDOW)
    try:
        if proc.stdin is not None:
            _ = proc.stdin.write(b"\n")
            _ = proc.stdin.flush()
    except (BrokenPipeError, OSError):
        pass
    if not wait_port_ready(WEB_PORT, WEB_APP_START_TIMEOUT):
        raise RuntimeError(f"web.exe 启动后 {WEB_APP_START_TIMEOUT}s 内端口仍未就绪")
    return proc

def shutdown_web_service(proc) -> None:
    """关闭 web.exe 并等待端口释放；非本模块启动的进程跳过（单一 owner 原则）。"""
    if proc is None:
        return
    try:
        proc.terminate()
    except Exception as e:
        _log(f"[1024服务] 终止 web.exe 异常: {e}")
    if wait_port_closed(WEB_PORT, WEB_APP_SHUTDOWN_TIMEOUT):
        return
    # 兜底：terminate 未生效时按端口定位 PID 强制结束（PyInstaller 单文件实际服务进程可能脱离引导进程）
    for pid in _find_port_pids(WEB_PORT):
        _force_kill(pid)

6.7 start_web.py —— 看板启动器管理镜像

核心逻辑：启动前确保镜像可用（起不来只告警、不阻断）；退出时复用批次单实例锁判断「有没有批次在跑」——抢得到才关，抢不到保留。

start_web.py（镜像相关片段）
def _stop_mirror(proc: "subprocess.Popen[bytes] | None") -> None:
    """退出时关闭本次启动的镜像；若有抓取批次在跑则保留。

    判据复用批次单实例锁（run_batch.acquire_single_instance_lock 是唯一实现）：
    抢得到 = 没有批次在跑，可以关；抢不到 = 批次在跑，关掉会让它整批请求失败。
    锁持有到关闭完成再释放，避免关的过程中恰好有批次启动、看到端口在听而跳过启动。"""
    if proc is None:
        return
    if _batch_lock is None:  # 未预加载成功：保守保留
        print("[1024镜像] 批次锁不可用，保守起见保留镜像不关闭", file=sys.stderr)
        return
    if not _batch_lock.acquire_single_instance_lock():
        print("[1024镜像] 检测到抓取批次正在运行，保留镜像不关闭（批次正在使用它）")
        return
    try:
        mirror_service.shutdown_web_service(proc)
    finally:
        _batch_lock.release_single_instance_lock()


def main() -> None:
    # ... 前置检查 ...
    # 1024 本地镜像：先确保可用再启动看板；只有本次真正启动的那一个才注册退出清理
    mirror_proc = _ensure_mirror() if args.mirror else None
    if mirror_proc is not None:
        _ = atexit.register(_stop_mirror, mirror_proc)
    # ... 启动 web 服务 ...
踩坑：_preload_batch_lock() 须在启动期加载 run_batch 模块——atexit 处理函数执行阶段解释器已关闭，不能再 import（会抛 can't register atexit after shutdown），导致镜像残留。
