### 方案 A：视觉层次增强

#### A4. 多段渐变色填充（升级现有渐变）

**实施状态**：✅ 已实施（2026-08-24）

**现状**：面积填充为两段渐变（顶部 0.22 → 底部 0.02 透明），层次感不足。

**优化建议**：
```
areaStyle: {
  color: new graphic.LinearGradient(0, 0, 0, 1, [
    { offset: 0,    color: 'rgba(47, 111, 237, 0.35)' },   // 顶部：高饱和度蓝
    { offset: 0.3,  color: 'rgba(47, 111, 237, 0.18)' },   // 上中：中等过渡
    { offset: 0.65, color: 'rgba(99, 102, 241, 0.10)' },   // 下中：蓝→紫过渡
    { offset: 1,    color: 'rgba(99, 102, 241, 0.01)' },   // 底部：紫色近透明
  ]),
}
```

**同时升级折线为渐变发光**：
```
lineStyle: {
  width: 3,
  color: new graphic.LinearGradient(0, 0, 1, 0, [
    { offset: 0, color: '#2f6fed' },    // 左端蓝
    { offset: 1, color: '#6366f1' },    // 右端紫
  ]),
  shadowColor: 'rgba(47, 111, 237, 0.35)',
  shadowBlur: 6,
  shadowOffsetY: 2,
}
```

**效果**：
- 面积三段渐变：深蓝 → 浅蓝 → 浅紫 → 透明，层次更丰富
- 折线蓝→紫渐变 + 微发光，视觉更高级
- 符合数据大屏的科技感风格

**同类参考**：AntV G2Plot 渐变线图、DataV 大屏模板。

**优先级**：⭐⭐⭐ 高

**风险评估**：低，纯视觉调整，不影响功能。

#### A5. 标准差区间带（异常可视化）

**实施状态**：✅ 已实施（2026-08-24）

**现状**：无数据波动范围参考，难以直观判断某一天是否异常。

**优化建议**：使用 `markArea` 绘制均值 ± 1 标准差的区间带：
```
// 计算标准差
const mean = avg
const std = Math.sqrt(data.reduce((s, v) => s + (v - mean) ** 2, 0) / data.length)
const upper = mean + std
const lower = Math.max(0, mean - std)

markArea: {
  silent: true,
  itemStyle: { color: 'rgba(47, 111, 237, 0.06)' },
  data: [[
    { yAxis: lower, itemStyle: { color: 'rgba(47, 111, 237, 0.04)' } },
    { yAxis: upper, itemStyle: { color: 'rgba(47, 111, 237, 0.08)' } },
  ]],
  label: { show: false },
}
```

**效果**：
- 浅蓝色半透明带标记正常波动范围
- 超出区间的日期自动被识别为异常
- 视觉参考线从「单条基准线」升级为「区间带」

**同类参考**：Grafana Standard Deviation Band、Zabbix 趋势图。

**优先级**：⭐⭐⭐ 高

**风险评估**：低，需注意 markArea 数据格式兼容性。

#### B4. 智能异常自动标注

**现状**：无法自动识别数据异常（突增、突降）。

**优化建议**：基于标准差自动检测异常值，用 markPoint 高亮标记：

```typescript
function detectAnomalies(data: number[], threshold = 2): number[] {
  const mean = data.reduce((s, v) => s + v, 0) / data.length
  const std = Math.sqrt(data.reduce((s, v) => s + (v - mean) ** 2, 0) / data.length)
  return data
    .map((v, i) => ({ v, i }))
    .filter(({ v }) => Math.abs(v - mean) > threshold * std)
    .map(({ i }) => i)
}

// 将异常点添加到 markPoint
const anomalyIndices = detectAnomalies(data, 2)
const anomalyPoints = anomalyIndices.map((i) => ({
  coord: [i, data[i]],
  value: '⚠',
  itemStyle: { color: '#f59e0b' },
  symbolSize: 36,
  tooltip: {
    formatter: () => {
      const deviation = ((data[i] - mean) / std).toFixed(1)
      return `异常值：偏离均值 ${deviation}σ`
    },
  },
}))
```

**效果**：
- 自动标记偏离均值 2σ 以上的异常点
- 橙色警告图标，吸引注意力
- Tooltip 显示偏离程度
- 无需人工预判，数据驱动

**同类参考**：Grafana Alert Annotations、Zabbix 触发器。

**优先级**：⭐⭐ 中

**风险评估**：
- 数据量较大时 markPoint 数量可能过多
- 建议限制最多标注 3-5 个最严重异常
- 初始实现可仅在 30/60/90 天模式下启用

### 方案 D：大屏动效增强

#### E1. 峰值/谷值脉冲增强

**实施状态**：✅ 已实施（2026-08-24）

**现状**：markPoint 静态展示最大/最小值，最新点有脉冲但峰值谷值没有。

**优化建议**：将静态 markPoint 改为双 effectScatter，不同颜色/周期：

```typescript
const maxIdx = data.indexOf(Math.max(...data))
const minIdx = data.indexOf(Math.min(...data))

// 最大值：金色脉冲
{
  type: 'effectScatter',
  coordinateSystem: 'cartesian2d',
  zlevel: 3,
  rippleEffect: { period: 3, scale: 5, brushType: 'stroke' },
  symbolSize: 14,
  itemStyle: { color: '#f59e0b' },
  data: [[maxIdx, data[maxIdx]]],
  tooltip: { show: false },
}
// 最小值：红色脉冲
{
  type: 'effectScatter',
  coordinateSystem: 'cartesian2d',
  zlevel: 3,
  rippleEffect: { period: 4, scale: 3, brushType: 'stroke' },
  symbolSize: 10,
  itemStyle: { color: '#ef4444' },
  data: [[minIdx, data[minIdx]]],
  tooltip: { show: false },
}
```

**效果**：
- 峰值金色脉冲 + 谷值红色脉冲，持续吸引注意力
- 脉冲周期不同（3s vs 4s）避免同步闪烁
- 视觉焦点自然引导到关键数据点
- 高度符合数据大屏风格

**同类参考**：DataV 大屏模板、ECharts effectScatter 动态标记。

**优先级**：⭐⭐⭐ 高

**风险评估**：

### 方案 F：体验与洞察增强（第三阶段新增）

#### F1. Tooltip 迷你趋势图（Sparkline）

**现状**：Tooltip 仅展示单日数据，缺乏上下文趋势感知。

**优化建议**：在 Tooltip 底部嵌入微型面积图，展示当前点前后 7 天走势：

```typescript
formatter: (params: any[]) => {
  // ... 现有 Tooltip 内容 ...
  
  // 构建迷你 sparkline（纯 CSS/SVG，不依赖 ECharts）
  const sparkData = data.slice(Math.max(0, idx - 3), Math.min(data.length, idx + 4))
  const maxS = Math.max(...sparkData)
  const minS = Math.min(...sparkData)
  const range = maxS - minS || 1
  const points = sparkData.map((v, i) => {
    const x = (i / (sparkData.length - 1)) * 80
    const y = 20 - ((v - minS) / range) * 18
    return `${x},${y}`
  }).join(' ')
  
  html += `<div style="margin-top:8px;padding-top:6px;border-top:1px solid rgba(255,255,255,0.1)">`
  html += `<div style="font-size:11px;color:#8b95a7;margin-bottom:4px">近7日走势</div>`
  html += `<svg width="80" height="22" style="display:block">`
  html += `<polyline points="${points}" fill="none" stroke="#2f6fed" stroke-width="1.5" opacity="0.8"/>`
  html += `</svg></div>`
  return html
}
```

**效果**：
- Tooltip 内直观看到当前点在近期趋势中的位置
- 判断是上升期还是下降期一目了然
- 轻量 SVG 方案，无额外渲染开销

**同类参考**：GitHub Commit Graph Tooltip、Linear Analytics Sparkline。

**优先级**：⭐⭐⭐ 高

**风险评估**：低，纯前端 SVG 绘制，兼容所有浏览器。

**现状**：数据全部依赖视觉呈现，用户需自行解读趋势。

**优化建议**：在统计条下方自动生成 1-2 条洞察文字：

```typescript
const trendInsights = computed(() => {
  if (!trend.value.length) return []
  const counts = trend.value.map(t => t.count)
  const insights: string[] = []
  
  // 周环比
  if (counts.length >= 14) {
    const firstHalf = counts.slice(0, 7).reduce((s, v) => s + v, 0)
    const secondHalf = counts.slice(7, 14).reduce((s, v) => s + v, 0)
    const pct = firstHalf > 0 ? (((secondHalf - firstHalf) / firstHalf) * 100).toFixed(1) : null
    if (pct && Math.abs(Number(pct)) > 5) {
      insights.push(`近7日较前7日${Number(pct) >= 0 ? '增长' : '下降'} ${Math.abs(Number(pct))}%`)
    }
  }
  
  // 连续趋势
  const recent = counts.slice(-3)
  if (recent.length === 3) {
    if (recent[2] > recent[1] && recent[1] > recent[0]) {
      insights.push('连续 3 日稳步增长 📈')
    } else if (recent[2] < recent[1] && recent[1] < recent[0]) {
      insights.push('连续 3 日持续下降 📉')
    }
  }
  
  // 异常检测
  const mean = counts.reduce((s, v) => s + v, 0) / counts.length
  const std = Math.sqrt(counts.reduce((s, v) => s + (v - mean) ** 2, 0) / counts.length)
  const maxDev = Math.max(...counts.map(v => Math.abs(v - mean) / (std || 1)))
  if (maxDev > 2) {
    insights.push('检测到异常波动，建议关注 🔍')
  }
  
  return insights.slice(0, 2)
})
```

**UI 展示**：
```vue
<div v-if="trendInsights.length" class="trend-insights">
  <span v-for="(text, i) in trendInsights" :key="i" class="insight-tag">
    {{ text }}
  </span>
</div>
```

**效果**：
- 数据自动"说话"，降低解读门槛
- 新用户快速获取关键信息
- 提升大屏的智能化感知

**同类参考**：Grafana Annotations、百度统计智能洞察。

**优先级**：⭐⭐⭐ 高

**风险评估**：低，纯前端计算，需注意洞察文本不要过于冗余。

#### F3. Y 轴智能自适应

**现状**：Y 轴从 0 开始，数据范围较大时浪费显示空间。

**优化建议**：动态计算 Y 轴范围，聚焦数据实际分布：

```typescript
const yAxisConfig = computed(() => {
  if (!data.length) return {}
  const max = Math.max(...data)
  const min = Math.min(...data)
  const padding = (max - min) * 0.15 || max * 0.1
  return {
    type: 'value',
    min: Math.max(0, Math.floor((min - padding) / 10) * 10),
    max: Math.ceil((max + padding) / 10) * 10,
    minInterval: 1,
    axisLabel: { formatter: (v: number) => String(Math.round(v)) },
    splitLine: {
      lineStyle: { color: '#f1f5f9', type: 'dashed', width: 1 },
    },
  }
})
```

**效果**：
- Y 轴自动聚焦数据范围，提升视觉精度

**同类参考**：Grafana Auto Scale、ECharts `scale: true`。

**优先级**：⭐⭐ 中

## 五、技术风险与约束

| 风险 | 说明 | 缓解措施 |
|------|------|----------|
| effectScatter 性能 | 多个脉冲动画同时运行 | 最多 3 个（最新+峰值+谷值），合理设置 zlevel |
| markArea 数据量 | 标准差区间带需精确计算 | 区间带仅 2 个数据点，无性能问题 |
| 同比对比请求 | B3 需额外请求去年数据 | 缓存结果，开关默认关闭 |
| Brush 组件体积 | 引入新组件增加打包体积 | 按需引入，tree-shaking |
| 移动端适配 | 新元素在窄屏可能拥挤 | 响应式断点隐藏次要元素 |
| 流光动画性能 | ECharts 流光可能影响帧率 | 优先使用 CSS 方案 |
| Sparkline SVG 性能 | F1 Tooltip 内嵌 SVG | 单图仅 7-8 个数据点，polyline 绘制极轻量 |
| 洞察文本准确性 | F2 洞察可能产生误导 | 仅在数据足够时触发（≥14 天），文案保守 |
| Y 轴自适应误导 | F3 用户可能误解数据起点 | 添加 "非从零开始" 视觉提示或 tooltip |
| visualMap 兼容性 | F8 与现有渐变冲突 | 初期仅作为区域增强，不移除现有渐变 |
