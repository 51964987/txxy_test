## 二、第二阶段优化方案

### 方案 A：视觉层次增强

#### A4. 多段渐变色填充（升级现有渐变）

**现状**：面积填充为两段渐变（顶部 0.22 → 底部 0.02 透明），层次感不足。

**优化建议**：
```
areaStyle: {
  color: new graphic.LinearGradient(0, 0, 0, 1, [
    { offset: 0,    color: 'rgba(47, 111, 237, 0.35)' },   // 顶部：高饱和度蓝
    { offset: 0.3,  color: 'rgba(47, 111, 237, 0.18)' },   // 上中：中等过渡
    { offset: 0.65, color: 'rgba(99, 102, 241, 0.10)' },   // 下中：蓝→紫过渡
    { offset: 1,    color: 'rgba(99, 102, 241, 0.01)' },   // 底部：紫色近透明
  ]),
}
```

**同时升级折线为渐变发光**：
```
lineStyle: {
  width: 3,
  color: new graphic.LinearGradient(0, 0, 1, 0, [
    { offset: 0, color: '#2f6fed' },    // 左端蓝
    { offset: 1, color: '#6366f1' },    // 右端紫
  ]),
  shadowColor: 'rgba(47, 111, 237, 0.35)',
  shadowBlur: 6,
  shadowOffsetY: 2,
}
```

**效果**：
- 面积三段渐变：深蓝 → 浅蓝 → 浅紫 → 透明，层次更丰富
- 折线蓝→紫渐变 + 微发光，视觉更高级
- 符合数据大屏的科技感风格

**同类参考**：AntV G2Plot 渐变线图、DataV 大屏模板。

**优先级**：⭐⭐⭐ 高

**风险评估**：低，纯视觉调整，不影响功能。

#### A5. 标准差区间带（异常可视化）

**现状**：无数据波动范围参考，难以直观判断某一天是否异常。

**优化建议**：使用 `markArea` 绘制均值 ± 1 标准差的区间带：
```
// 计算标准差
const mean = avg
const std = Math.sqrt(data.reduce((s, v) => s + (v - mean) ** 2, 0) / data.length)
const upper = mean + std
const lower = Math.max(0, mean - std)

markArea: {
  silent: true,
  itemStyle: { color: 'rgba(47, 111, 237, 0.06)' },
  data: [[
    { yAxis: lower, itemStyle: { color: 'rgba(47, 111, 237, 0.04)' } },
    { yAxis: upper, itemStyle: { color: 'rgba(47, 111, 237, 0.08)' } },
  ]],
  label: { show: false },
}
```

**效果**：
- 浅蓝色半透明带标记正常波动范围
- 超出区间的日期自动被识别为异常
- 视觉参考线从「单条基准线」升级为「区间带」

**同类参考**：Grafana Standard Deviation Band、Zabbix 趋势图。

**优先级**：⭐⭐⭐ 高

**风险评估**：低，需注意 markArea 数据格式兼容性。

#### B4. 智能异常自动标注

**现状**：无法自动识别数据异常（突增、突降）。

**优化建议**：基于标准差自动检测异常值，用 markPoint 高亮标记：

```typescript
function detectAnomalies(data: number[], threshold = 2): number[] {
  const mean = data.reduce((s, v) => s + v, 0) / data.length
  const std = Math.sqrt(data.reduce((s, v) => s + (v - mean) ** 2, 0) / data.length)
  return data
    .map((v, i) => ({ v, i }))
    .filter(({ v }) => Math.abs(v - mean) > threshold * std)
    .map(({ i }) => i)
}

// 将异常点添加到 markPoint
const anomalyIndices = detectAnomalies(data, 2)
const anomalyPoints = anomalyIndices.map((i) => ({
  coord: [i, data[i]],
  value: '⚠',
  itemStyle: { color: '#f59e0b' },
  symbolSize: 36,
  tooltip: {
    formatter: () => {
      const deviation = ((data[i] - mean) / std).toFixed(1)
      return `异常值：偏离均值 ${deviation}σ`
    },
  },
}))
```

**效果**：
- 自动标记偏离均值 2σ 以上的异常点
- 橙色警告图标，吸引注意力
- Tooltip 显示偏离程度
- 无需人工预判，数据驱动

**同类参考**：Grafana Alert Annotations、Zabbix 触发器。

**优先级**：⭐⭐ 中

**风险评估**：
- 数据量较大时 markPoint 数量可能过多
- 建议限制最多标注 3-5 个最严重异常
- 初始实现可仅在 30/60/90 天模式下启用

### 方案 D：大屏动效增强

#### E1. 峰值/谷值脉冲增强

**现状**：markPoint 静态展示最大/最小值，最新点有脉冲但峰值谷值没有。

**优化建议**：将静态 markPoint 改为双 effectScatter，不同颜色/周期：

```typescript
const maxIdx = data.indexOf(Math.max(...data))
const minIdx = data.indexOf(Math.min(...data))

// 最大值：金色脉冲
{
  type: 'effectScatter',
  coordinateSystem: 'cartesian2d',
  zlevel: 3,
  rippleEffect: { period: 3, scale: 5, brushType: 'stroke' },
  symbolSize: 14,
  itemStyle: { color: '#f59e0b' },
  data: [[maxIdx, data[maxIdx]]],
  tooltip: { show: false },
}
// 最小值：红色脉冲
{
  type: 'effectScatter',
  coordinateSystem: 'cartesian2d',
  zlevel: 3,
  rippleEffect: { period: 4, scale: 3, brushType: 'stroke' },
  symbolSize: 10,
  itemStyle: { color: '#ef4444' },
  data: [[minIdx, data[minIdx]]],
  tooltip: { show: false },
}
```

**效果**：
- 峰值金色脉冲 + 谷值红色脉冲，持续吸引注意力
- 脉冲周期不同（3s vs 4s）避免同步闪烁
- 视觉焦点自然引导到关键数据点
- 高度符合数据大屏风格

**同类参考**：DataV 大屏模板、ECharts effectScatter 动态标记。

**优先级**：⭐⭐⭐ 高

**风险评估**：
- 低，需确保不与现有最新点脉冲冲突
- 三个 effectScatter 同时动画需注意性能

**现状**：折线为静态，仅入场时有逐点描线效果。

- 提升科技感
- CSS 方案更轻量，推荐使用

**同类参考**：DataV 大屏流光效果、AntV 动态线图。

**优先级**：⭐⭐ 中

## 五、技术风险与约束

| 风险 | 说明 | 缓解措施 |
|------|------|----------|
| effectScatter 性能 | 多个脉冲动画同时运行 | 最多 3 个（最新+峰值+谷值），合理设置 zlevel |
| markArea 数据量 | 标准差区间带需精确计算 | 区间带仅 2 个数据点，无性能问题 |
| 同比对比请求 | B3 需额外请求去年数据 | 缓存结果，开关默认关闭 |
| Brush 组件体积 | 引入新组件增加打包体积 | 按需引入，tree-shaking |
| 移动端适配 | 新元素在窄屏可能拥挤 | 响应式断点隐藏次要元素 |
| 流光动画性能 | ECharts 流光可能影响帧率 | 优先使用 CSS 方案 |
