# 数据总览大屏展示优化方案（排行榜轮播与动态数据展示）

> 状态：**待确认**（确认后再实施代码变更）
> 涉及页面：`web/frontend/src/views/DashboardView.vue`
> 变更范围：纯前端展示层，无后端 / 数据库 / 接口变更

---

## 一、项目概述

本方案面向【数据总览】页面（Dashboard），目标是通过参考 B 端数据大屏同类优秀项目，补齐展示细节、统一视觉语言、提升数据跳动/轮播的生动感，使用户在进入首页时即可直观感受到数据活力。

### 1.1 本次优化范围

1. **【版块分布】排行榜**：更换展示类型，支持列表数据无缝向上循环滚动。
2. **【每日新增趋势（近 30 天）】卡片**：实现数据实时跳动/更新效果。
3. **【版块分布】卡片（环形图 + 排行榜）**：实现数据自动轮播/高亮/跳动效果。

### 1.2 设计原则

- **纯前端动画**：不新增接口请求，所有动效基于已有数据渲染。
- **可暂停、可交互**：用户悬停时暂停自动动效，避免抢占操作。
- **卸载即清理**：组件销毁时取消 `requestAnimationFrame` / `setInterval`，避免内存泄漏。
- **性能优先**：使用 CSS 动画、`requestAnimationFrame`、ECharts 原生 `animationDurationUpdate` 等低成本方案。

## 二、同类项目调研结果

### 2.1 DataV（阿里大屏组件库）- 排名轮播表 `scrollRankingBoard`

**来源**：DataV 官方文档 - 排名轮播表 `http://datav.jiaminghi.com/guide/scrollRankingBoard.html`

**核心能力**：

| 能力 | 说明 |
|---|---|
| 单条滚动 | 每次滚动一行数据（默认） |
| 整页滚动 | 每次滚动一整页数据 |
| 自动排序 | 默认按 `value` 自动排序 |
| 数值单位/格式化 | 支持 `unit`、`valueFormatter` 自定义展示 |
| 行排名 | `valueFormatter` 回调内可拿到 `ranking` 排名参数 |
| 自定义 name | `name` 使用 `v-html` 渲染，可插入 HTML 实现彩色/图标效果 |

**关键配置**：

```js
{
  data: [{ name: '南阳', value: 120 }, { name: '周口', value: 55 }, /* ... */ ],
  rowNum: 5,
  waitTime: 2000,
  carousel: 'single', // 'single' | 'page'
  unit: '单位',
  sort: true,
  valueFormatter({ name, value, percent, ranking }) {
    return value.toLocaleString()
  }
}
```

**对本项目的启发**：
- 排行榜应突出**名次（ranking）**，Top 行可通过颜色/徽章强化。
- 滚动节奏建议 `2s` 左右一行，用户既能看清内容又保持动态感。
- 数值需做千分位/单位格式化，提升可读性。

### 2.2 DataV - 轮播表 `scrollBoard`

**来源**：DataV 官方文档 - 轮播表 `http://datav.jiaminghi.com/guide/scrollBoard.html`

**核心能力**：

| 能力 | 说明 |
|---|---|
| 表头与行号 | 支持 `header`、`index` 显示行号 |
| 列宽与对齐 | `columnWidth`、`align` 可自定义 |
| 单条/整页轮播 | `carousel: 'single' / 'page'` |
| 悬停暂停 | `hoverPause: true`（默认开启） |
| HTML 单元格 | 数据通过 `v-html` 渲染，支持彩色文字、图标 |
| 动态追加 | 提供 `updateRows` 方法，追加数据而不从头轮播 |

**关键配置**：

```js
{
  header: ['列1', '列2', '列3'],
  data: [
    ['<span style="color:#37a2da;">行1列1</span>', '行1列2', '行1列3'],
    /* ... */
  ],
  index: true,
  columnWidth: [50],
  align: ['center'],
  carousel: 'single',
  hoverPause: true,
  waitTime: 2000
}
```

**对本项目的启发**：
- 行号/排名是数据大屏排行榜的标配，可显著提升信息识别效率。
- 轮播表应具备**悬停暂停**能力，尊重用户当前阅读焦点。
- 双份渲染的无缝滚动方案与 DataV 轮播思路一致，可继续沿用。

### 2.3 ECharts 实时数据更新与动画

**参考来源**：ECharts 官方 `animationDurationUpdate`、`universalTransition`、`setOption` 实践，以及 CSDN/腾讯云/百度等社区方案。

**核心能力**：

| 能力 | 配置项 | 效果 |
|---|---|---|
| 数据更新平滑过渡 | `animationDurationUpdate` | 数据变化时旧点/柱/扇区平滑过渡到新位置，避免生硬切换 |
| 入场生长动画 | `animationDuration` + `animationDelay` | 折线逐点描出、柱状图逐根升起 |
| 缓动函数 | `animationEasing: 'cubicOut'` | 符合物理直觉的减速效果 |
| 轮播高亮 | `dispatchAction({ type: 'highlight', dataIndex })` | 自动高亮扇区、柱条，模拟数据「跳动」 |
| 性能优化 | `lazyUpdate`、`notMerge` | 频繁更新时减少重绘 |

**典型实时更新模式**：

```js
// 趋势图：新数据平滑替换
chart.setOption({
  xAxis: { data: newDates },
  series: [{ data: newValues }]
}, {
  lazyUpdate: false,
  animationDurationUpdate: 600,
  animationEasing: 'cubicOut'
})

// 环形图：自动轮播高亮
chart.dispatchAction({ type: 'downplay', seriesIndex: 0 })
chart.dispatchAction({ type: 'highlight', seriesIndex: 0, dataIndex: nextIndex })
```

**对本项目的启发**：
- 趋势图更新时应启用 `animationDurationUpdate`，让折线「流动」到新数据。
- 环形图通过 `dispatchAction` 实现自动轮播高亮，中心文字联动，增强「实时感」。
- 动画时长建议 600~900ms，过长会显得拖沓，过短则缺乏视觉停留。

### 2.4 数字滚动/跳动组件

**常见实现**：`CountUp.js`、`vue-count-to` / `vue3-count-to`、`gsap.number`、自研 `requestAnimationFrame` 插值。

**核心能力**：

| 能力 | 说明 |
|---|---|
| 从旧值滚动到新值 | `easeOutCubic` / `easeOutExpo` 缓动 |
| 千分位格式化 | 滚动过程中同步显示 `toLocaleString()` |
| 自动触发 | 数据刷新时自动重新滚动 |
| 无依赖轻量 | 自研组件约 60~100 行，无需额外库 |

**对本项目的启发**：
- KPI 统计卡使用数字滚动，可在数据刷新时营造「数据跳动」效果。
- 采用 `requestAnimationFrame` 自研即可，避免引入额外依赖。

## 三、当前项目已实施方案对照

上一轮已完成以下动态化改造，并与同类项目做法基本一致：

| 卡片 | 当前实现 | 对应同类项目做法 |
|---|---|---|

## 四、本次查漏补缺：排行榜展示优化

### 4.1 问题描述

1. **缺序号**：排行榜行内无排名数字，顺序仅靠行序体现，识别效率低。
2. **展示类型单一**：当前为「横向进度条式列表」，不符合 B 端大屏常见的「名次徽章 + 名称 + 数值」风格。

### 4.2 展示类型方案对比

| 方案 | 展示类型 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| **A. DataV 风格排名列表（推荐）** | 左侧名次徽章（金银铜）+ 版块名 + 副信息 + 右侧数值/占比 | 序号醒目、信息密度高、可延续无缝滚动动效、与 DataV 大屏主流做法一致 | 仍是列表形态，视觉创新有限 | ✅ 推荐 |
| B. ECharts 横向条形图 | 横向柱状图 + 名次标签 + 渐变填充 | 图表感强、动画平滑 | 历史上有过「窄卡片 bar 渲染异常」问题；与「循环向上滚动」诉求冲突 | 备选 |
| C. 轮播大卡片 | 每屏突出展示 1 个版块 | 视觉冲击力强 | 信息密度低，无法一眼看全排名 | 备选 |

### 4.3 推荐方案 A 详细设计

#### 4.3.1 每行展示结构

```
┌─────┬───────────────────┬──────────────┬─────────────────┐
│ ①  │ 技术交流(7)        │ 今日新增 128  │ 45,218 条 (37%) │
└─────┴───────────────────┴──────────────┴─────────────────┘
│ 名次 │ 版块名称(fid)      │ 副信息        │ 数值 · 占比       │
```

- **名次徽章**：1/2/3 复用现有 `rankClass` / `rank-gold` / `rank-silver` / `rank-bronze` 样式体系（与「点赞最高帖」榜的徽章风格一致）；4 名以后用深色序号徽章（`rank-plain`）。
- **版块名称**：保留 `名称(fid)`，单行省略。
- **副信息**：`今日新增 N`（数据源已有 `today_count`）。
- **右侧数值**：`条数 + 占比`，保留 hover title 的「最近抓取 / 今日 / 昨日」详情。

#### 4.3.2 关键实现点（双份列表序号取模）

当前 `barLoopList` 为 `[...fidDist, ...fidDist]` 双份渲染（无缝滚动基础），模板内**序号必须取模**：

```ts
const barLoopItems = computed(() =>
  fidDist.value.flatMap((item, i) => [
    { item, rank: i + 1 },
    { item, rank: i + 1 },
  ]),
)
```

若直接使用 `i + 1`，第二份列表会显示 14~26 的错误名次。

#### 4.3.3 布局样式

- 行布局改为 `grid-template-columns: 28px minmax(80px, 1fr) auto auto`（徽章 / 名称 / 副信息 / 数值）。
- 徽章列固定宽度、左右居中，防止数字跳动时行宽抖动。
- 窄屏（≤1100px）隐藏副信息列，仅保留徽章 + 名称 + 数值。

#### 4.3.4 动效保留

- 无缝向上循环滚动逻辑（`startBarScroll` / `stopBarScroll` / `barPaused`）**原样保留**。
- 悬停暂停、点击跳转版块、hover 详情 title 全部保留。
- 数据刷新后由现有 `loadP0` 末尾自动重启滚动，无需额外改动。
