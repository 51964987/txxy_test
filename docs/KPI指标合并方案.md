# KPI 指标合并方案（7 张 → 4 张，一行展示）

> 目标：当前数据总览首屏 KPI 区展示 7 张卡片，信息偏散、视觉拥挤。参考互联网数据大屏/运营驾驶舱（如阿里 DataV、Grafana、各社区运营后台）的惯例——**顶部 KPI 条一行等分、每张卡主指标 + 副指标双层结构**，将 7 张合并为 4 张，信息无损。
> 状态：✅ 已实施（2026-08-26）。已按本方案落地于 `DashboardView.vue` 与 `style.css`，与当前代码一致。

## 一、合并对照表（信息无损）

| 合并后卡片 | 主指标 | 副指标（合并内容） | 原来源 |
|---|---|---|---|
| 累计帖子 | `total` | 今日 +`today` · 覆盖 N 版块（版块总数并入） | 累计帖子卡 + 版块总数卡 |
| 今日新增 | `today` | 较昨日环比（`kpiSub.todayDiff`）· 昨日绝对值 `yesterday` | 今日新增卡 + 昨日新增卡 |
| 近 7 日新增 | `week_new` | 日均 `weekAvg` · 昨日占近 7 日% `yesterdayShare` | 近7日新增卡 + 昨日卡的占比信息 |
| 累计用户 | `total_users` | 活跃数 `active_users` · 活跃率% `activeShare` | 累计用户卡 + 活跃用户卡 |

> 说明：原 7 个字段（`total` / `today` / `yesterday` / `week_new` / `total_users` / `active_users` / `fidDist.length`）全部保留，仅去掉重复维度的独立卡，没有丢数据。

## 二、布局建议（参考互联网）

- **宽屏（>1100px）**：4 张严格一行，`grid-template-columns: repeat(4, 1fr)`，等分铺满，符合驾驶舱"一眼扫完核心指标"的扫读习惯。
- **中屏（≤1100px）**：`repeat(2, 1fr)` → 2×2 网格，仍工整。
- **窄屏（≤640px）**：`1fr` 单列竖排，手机可读。
- 每张卡内部结构：`图标 + 主指标数字（RollingNumber 滚动） + 副指标（两行/并排，flex-wrap）`。

## 三、参考互联网的做法要点

1. **KPI 条一行等分**：主流大屏首屏顶部都是一行 N 等分卡（N 多为 4~6），不折行、不空位。
2. **主+副双层**：主指标是大数字，副指标是小字补充说明（环比、占比、对比值），而非再开一张卡。
3. **相邻日维度合并**：今日 / 昨日是同维度相邻日，合并进一张卡用副指标对比，避免重复。
4. **强相关数据归并**：累计用户 + 活跃用户是同一主体（活跃率=活跃/累计），合并为一张"用户"卡。
5. **结构性常量并入**：版块总数是结构性维度，并入"累计帖子"副指标（"覆盖 N 版块"）比单独开卡更紧凑。

## 四、实施影响（代码侧）

- `DashboardView.vue`：KPI 模板由 7 张 `stat-card` 改为 4 张，副指标用 `stat-sub` 双 span 并排（`flex-wrap` 已支持）。
- `style.css`：`.stat-grid` 由 `repeat(6,1fr)` 改为 `repeat(4,1fr)` + 响应式降级；骨架卡数量 7→4。
- 后端接口 `/stats/overview` 无需改动（字段已全）。
